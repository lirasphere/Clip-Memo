# Clip-Memo（一時メモ）

コードブロックや追跡番号などを、一時的に退避しておくための自分用クリップボードメモです。

https://lirasphere.github.io/Clip-Memo/

## 特徴

- ボタン一発でクリップボードの内容を追加、コピー、消去
- タグで整理（タグでの絞り込みつき）
- PC・スマホ対応のPWA（ホーム画面に追加して使えます）
- GitHubのシークレットGistによる端末間同期（任意）
- ライトモードのみ

## 使い方

- **追加**：画面下の「クリップボードから追加」を押します。PCでは、どこにもフォーカスがない状態で Cmd+V（Ctrl+V）でも追加できます。
- **コピー**：カードの「コピー」を押します。
- **消去**：カードの「消去」を押します。5秒間は「元に戻す」が出ます。
- **タグ**：カードの「＋タグ」で追加します。フィルタ中に追加したメモには、そのタグが自動で付きます。
- **手入力**：クリップボードを読み取れないときは、貼り付け用の入力欄が開きます。
- **設定**：「コピーしたらメモを消去する」をオンにすると、コピーと同時にメモが消えます。

## 同期

1. [gist権限だけのトークン](https://github.com/settings/tokens/new?scopes=gist&description=clipboard-memo)を作ります。
2. アプリの「設定」でトークンを貼り付け、「保存して同期」を押します。
3. 他の端末でも同じトークンを入れると、同じデータにつながります。

編集の約1秒後、アプリを開いたとき、画面に戻ったときに自動で同期します。

### 同期を解除する

「設定」でトークン欄を空にして「保存して同期」を押します（端末ごとに行います）。GitHub側では、トークンの削除と `clipboard-memo.json` のGistの削除ができます。

## ホーム画面への追加

- **iPhone**：Safariで開き、共有ボタンから「ホーム画面に追加」
- **Android・PC（Chrome）**：メニューの「アプリをインストール」

## 注意

- シークレットGistは、URLを知っている人には見られます。パスワードやAPIキーは入れないでください。
- Gistには編集履歴が残ります。
- トークンは、その端末のブラウザ内にだけ保存されます。他人に見せないようにしてください。
- ブラウザの「サイトデータ」を消すと、その端末のメモとトークンが消えます。同期済みのメモは、トークンを入れ直せば戻ります。
